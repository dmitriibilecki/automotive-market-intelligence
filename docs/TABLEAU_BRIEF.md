# Tableau: synthetic vehicle-market demonstration

Run `python demo.py` and use the generated `output/brand_summary.csv`.
All 240 vehicles are fictional. The original observation archive and its aggregates remain private.

## Suggested dashboard

1. Header: "Vehicle asking prices - synthetic demonstration".
2. Cards: fictional records and number of brands.
3. Bar chart: median asking price by brand.
4. Detail table: brand, count, median asking price and median mileage.

Do not present these values as market estimates, transaction prices, price trends or investment recommendations. The synthetic generator sets different brand baselines by construction.
